# 🌐 Maintaining IoT Classification under Concept Drift

This repository accompanies the paper

> **Maintaining IoT Device Identification under Concept Drift via Budget-Aware Traffic Labeling**

submitted to the **IEEE Internet of Things Journal (IoT-J)**.

The repository serves as the public landing page for the data collected and used in our paper. The data will be shared upon the paper publication.


## 📄 Citation

If you use our dataset, please cite:

> S. Azizi et al., *Maintaining IoT Device Identification under Concept Drift via Budget-Aware Traffic Labeling*, IEEE Internet of Things Journal (IoT-J), 2026.
